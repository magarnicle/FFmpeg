  New Deferred Device Initialization �


  How It Works:

  When another process is using the DeckLink card, ffmpeg will now:
  1. Continue encoding/filtering immediately - no blocking
  2. Fill the async buffer while waiting for the card
  3. Automatically enable hardware output when card becomes available
  4. Start playout seamlessly from the pre-filled buffer
